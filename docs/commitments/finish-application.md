## Goal

Finish the original desktop product: useful process controls, complete customization, appearance, named presets, a deliberate first-launch layout and a runnable Linux package. The developer selected this work by asking to finish the application. [Application requirements](../spec/application.md) derive from the original product specification; the [execution plan](../plans/finish-application.md) names the remaining changes.

The earlier GPU commitment remains incomplete. Its requirements are retained here, including missing native hardware and the Mac F1 review obligation. Preparing a usable Linux build does not assert those checks passed. The optional platform-priority question has not been answered; no hardware requirement has been silently dropped.

## Done when

The APP, LIVE and GPU checks named above have valid passing evidence and final review has no open finding. A Linux build may be handed over as a clearly scoped usable checkpoint before the outstanding hardware evidence exists. No merge, push, deployment or public release is authorized by this commitment.
